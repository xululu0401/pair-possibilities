# 抽签可能性台
2–16人单轮无向配对：回避/锁定约束、精确组合计数、逐对占比、前12方案预览。

运行：直接打开index.html或静态HTTP服务，无后端、无外部依赖。编辑core.js/ui.js/template.html后运行`node build.cjs`。测试`node --test tests/core.test.cjs`。

位掩码递归F(0)=1，固定集合最小编号，遍历允许的搭档递归累计。每个完整配对只计一次。锁定边先移除两端，未锁定允许边出现次数等于移除其两端的余图计数。16人最多15!!=2027025，整数精确。

占比只基于所有可行完整方案等可能，不代表顺序抽球、真实赛事概率或比赛胜率；不支持轮空、多个轮次或未输入的赛事规则。不实施抽签。名单只在当前浏览器计算，显式保存至localStorage；JSON备份自管。CSV含准确分子分母；PNG首方案摘要；MD最多12预览。

默认虚构6人，回避1-2、3-4，容斥得10种；锁定1-3后3种。5组测试包含100组独立全排列去重对照总数与各边出现数、无解/非法/上限。
